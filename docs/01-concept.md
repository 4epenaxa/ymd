# 01. Концепция

## Проблема

Официальный клиент — 350 МБ Electron с Chromium, собственным renderer'ом и
анимациями, которые не нужны в тайловом окружении. Для niri + Noctalia нужен
клиент, который **живёт в баре**: минимум площади, мгновенный отклик, ноль
анимаций, цвета из палитры обоев.

При этом музыка — не «фоновый значок»: нужен доступ к библиотеке, волне, лайкам,
текстам и офлайну. Значит, нужен не «ещё один mini-player», а полноценный клиент
с двумя поверхностями: **виджет (всегда) и панель (по требованию)**.

## Видение

> Яндекс Музыка, которая выглядит как часть бара: одна строка, цвет палитры,
> ноль движения — и полный доступ к библиотеке в панели по клику.

## Цели

1. **Паритет функций** с официальным клиентом во всём, что имеет смысл вне
   Electron-окна (см. `05-feature-matrix.md`): вход, каталог, поиск, волна,
   лайки/дизлайки, плейлисты, очередь, тексты, офлайн-загрузка, синхронизация
   между устройствами.
2. **Нативность**: PipeWire через GStreamer, MPRIS для шелла и медиа-клавиш,
   токен в GNOME Keyring, systemd-сервис вместо «приложения в трее».
3. **Минимализм**: ни одной анимации по умолчанию; ни одного захардкоженного
   цвета; один акцент и один шрифт (из бара).
4. **Адаптивность к окружению**: виджет меняет плотность и видимость по состоянию
   niri (fullscreen, overview, фокус), простою, питанию и палитре.
5. **Устойчивость к изменениям API**: вся работа с непубличным API — в демоне,
   за типизированным слоем; плагин не знает про эндпоинты.

## Не-цели

- Не воспроизводим Chromium-рендерер и веб-клиент целиком.
- Не поддерживаем compositor'ы, кроме niri (поведение деградирует мягко).
- Не делаем «второй Spotify»: только Яндекс Музыка.
- Не храним токен в плагине: плагин вообще не видит секретов.
- Не боремся за пиксель-в-пиксель с оригиналом: другой носитель — другие законы.

## Принципы

| # | Принцип | Следствие |
|---|---|---|
| P1 | **Бар — не панель** | В баре только состояние и 2–3 действия; всё остальное — в панели |
| P2 | **Ноль движения** | Нет переходов, marquee, пульсаций; прогресс обновляется шагом, а не анимацией |
| P3 | **Палитра — единственный источник цвета** | `noctalia.getColor(role)`; hex допустим только в настройках пользователя |
| P4 | **Мгновенность** | Локальное состояние в Luau; сеть — только через демон; оптимистичный UI |
| P5 | **Одна правда** | Состояние плеера живёт в демоне; плагин — проекция, а не второй источник |
| P6 | **Деградация, не отказ** | Нет niri → статичный режим; нет демона → виджет показывает «offline» и кнопку запуска |
| P7 | **Ничего лишнего на экране** | Пустые состояния не рисуем: нет трека — нет виджета (настраиваемо) |

## Поверхности

| Поверхность | Роль | Где |
|---|---|---|
| Бар-виджет | состояние + play/pause + переход в панель | бар Noctalia |
| Панель | поиск, библиотека, очередь, волна, тексты, загрузки | `ui.*` дерево, popup |
| Шорткат | play/pause, лайк, волна | control center |
| Launcher provider | `>ym <запрос>` — «включить трек» | лаунчер Noctalia |
| Уведомления | смена трека (off by default) | `noctalia.notify` |

## Режимы виджета

Настройка `mode`: `auto` (по умолчанию) | `full` | `compact` | `dot` | `hidden`.

| Режим | Вид | Когда выбирается в `auto` |
|---|---|---|
| `full` | glyph + «Трек — Артист» (обрезка) + время | играет и окно не fullscreen |
| `compact` | glyph + трек (без артиста) | играет, но места мало: fullscreen, узкий бар, батарея |
| `dot` | только glyph | пауза дольше N минут, или `hide_when_paused` |
| `hidden` | ничего | niri overview открыт, простой > N, `mode=hidden` |

Правила `auto` — упорядоченный список условий в демоне (`env` state), плагин лишь
применяет результат. Так правила тестируются вне GUI.

## Сценарии

**Работа.** Бар сверху, fullscreen-терминал. Виджет — только glyph. Медиа-клавиша
ставит на паузу; при снятии fullscreen возвращается `full`.

**Фокус.** Демон видит fullscreen-окно > 30 мин и `auto` уходит в `dot`;
уведомления о смене трека выключены; MPRIS продолжает работать для блокировки.

**Вечер.** Палитра меняется на тёмную/тёплую — виджет меняет цвет без перезапуска
(`noctalia.getColor` читается в `update()`).

**Поиск.** `Super → >ym кино` в лаунчере → трек играет; панель не открывалась.

**Офлайн.** Панель: у альбома значок «скачано»; в самолёте играет из кэша,
виджет показывает `offline`-точку.

## Метрики успеха

| Метрика | Цель |
|---|---|
| Потребление памяти | демон < 80 МБ RSS, плагин — часть процесса Noctalia (не расти) |
| Задержка «клик → звук» | < 300 мс для локального кэша, < 1.5 с для сети |
| Время до первого кадра виджета | < 50 мс после старта бара |
| Правки при изменении API | только в `ym-api` демона, плагин не трогаем |
| Анимации | 0 по умолчанию; включение — одна настройка |

## Ограничения и этика

- API непубличный: возможны блокировки и изменение схем (см. `08-risks.md`).
- Свой OAuth-клиент обязателен: `redirect_uri` официального привязан к
  `music-application://desktop`.
- Офлайн-кэш расшифровывается технически (`encraw` — транспортное шифрование,
  не DRM), но правовая сторона — на пользователе.
- Плагин доверенный: он исполняется в VM Noctalia, но имеет доступ к ФС и
  процессам — поэтому в нём нет секретов и нет прямой работы с API.
