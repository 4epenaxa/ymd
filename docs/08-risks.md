# 08. Риски и открытые вопросы

## Риски

| # | Риск | Влияние | Вероятность | Смягчение |
|---|---|---|---|---|
| R1 | Непубличный API меняется | среднее | высокая | всё в `ym-api`, типы с `serde(default)`, `doctor` показывает расхождения, быстрый релиз демона без плагина |
| R2 | Официальный OAuth-клиент не даёт loopback | высокое | средняя | `S9`: свой клиент в Яндекс ID; фоллбэк — `ymd auth import` (URL с токеном) |
| R3 | `barWidget.*` в v5 уже не тот, что в примерах | высокое | низкая | `S2`: спайк до кода; при нехватке — `ui.*`-дерево в виджете |
| R4 | `plugin_api` установленного хоста ниже нужного | высокое | низкая | `S1`; при необходимости понизить требования (`getColor` → hex-fallback, без `idle.watch`) |
| R5 | Бюджеты Luau-вызова рвут UI | среднее | средняя | вся сеть — только через демон, `update()` ≤ 1 мс, списки — пагинация |
| R6 | GStreamer-дев-пакеты не установлены у пользователя | среднее | высокая (у нас так) | `backend = "mpv"` как альтернатива; `doctor` проверяет `gst-launch-1.0` |
| R7 | Токен в libsecret недоступен (нет `gnome-keyring`/`kwallet`) | среднее | низкая | файл `0600` как фоллбэк с явным предупреждением |
| R8 | Дублирование со встроенным виджетом `media` | низкое | высокая | наш виджет — надстройка; в README: «можно оставить только `media`, он работает через MPRIS» |
| R9 | Яндекс блокирует сторонние клиенты по `deviceId`/заголовкам | высокое | средняя | не подделываем чужие `deviceId`; честный `x-yandex-music-device`; при блокировке — деградация до MPRIS-управления официальным клиентом |
| R10 | Юридические ограничения на офлайн-расшифровку | среднее | низкая | фича за флагом, по умолчанию выключена, предупреждение в настройках |

## Решения (decision log)

| # | Решение | Альтернативы | Почему |
|---|---|---|---|
| D1 | Демон на Rust + плагин Luau | чистый Luau; Tauri-приложение | Luau не умеет аудио/крипту; отдельное окно — мимо бара |
| D2 | HTTP+SSE для IPC | DBus; Unix-socket; CLI-спавн | `noctalia.http`/`httpStream` — штатные API; push вместо поллинга |
| D3 | MPRIS как обязательный интерфейс | только свой протокол | бесплатно даёт шелл, клавиши, lockscreen, встроенный виджет |
| D4 | `plugin_api = 35` | 3 (максимум совместимости) | нужны `getColor` (31), `hover_highlight` (34); хосты ниже — через `[[plugin.release]]` |
| D5 | Логика `auto`-режима в демоне | в плагине | тестируется без GUI, единый источник правды |
| D6 | Токен только в libsecret | файл; в плагине | плагин доверенный, но скрипт не должен видеть секреты |
| D7 | Ноль анимаций по умолчанию | анимации «как в оригинале» | требование пользователя и принцип P2 |

## Проверки перед релизом

- [ ] `ymd doctor` без предупреждений на чистом хосте.
- [ ] Плагин выключается/включается без перезапуска Noctalia.
- [ ] Демон перезапускается — виджет восстанавливает состояние < 2 с.
- [ ] Нет ни одного `#rrggbb` в коде плагина (`grep` в CI).
- [ ] Нет `setNeedsFrameTick` при `animations = false`.
- [ ] Нет `sh -c` с пользовательскими данными (`runAsync` — только argv).
- [ ] Токен не появляется в логах (`ymd doctor` и `RUST_LOG=debug`).
